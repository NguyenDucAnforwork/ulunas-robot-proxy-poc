UL-UNAS -- WASM Fallback Demo

This is NOT a native-performance demo. It runs the real UL-UNAS model (runtime-free C engine + real trained F_PROXY_ROBOT weights) compiled to WebAssembly, in a browser, as a fallback for when no Mac/Xcode/physical iPhone is available to build the real iOS app (see IOS_BUILD_AND_DEMO.md). It does not demonstrate native ARM64/NEON performance (WASM has no NEON), and it has never been run in an actual browser -- only Node.js-verified, see the note below.
No echo cancellation. Use wired headphones. Playing this page's output through your device's speaker while the microphone is open will cause audio feedback.
Model status: this build runs the real noise-suppression model (same runtime-free C engine validated in mobile/c_neon/, real F_PROXY_ROBOT trained weights) -- not a passthrough. It is verified against a native-x86 build of the identical source on the same input, in Node.js (test_wasm_node.js): outputs match to within ~0.025 after the model's own documented 2-hop startup transient (that transient itself diverges much more between native and WASM builds -- a real, measured cross-compiler floating-point sensitivity in that specific warm-up window, not a bug in either build individually -- see that file's comments). It has never been exercised with a real microphone in a real browser.
